
# =============================================================================
# sythball 3D数据 (8chunk/125f) - 4dirback 数据集完整训练流程
#   4dirback: 前半程固定 W/S/A/D，后半程切换为相反方向 S/W/D/A（尽量回到原点）
#   目标：让训练真正进入 out-window + memory selection（FOV overlap）分支
# =============================================================================
#
# 关键对齐（官方实现）：
# - VAE 时间压缩比 r=4（对应 latent_T = (F-1)//4 + 1）
# - 1 chunk = 4 个 latent（AR 的 chunk-wise causal / memory 选择均以 4 对齐）
# - 8 chunks => latent_T = 8*4 = 32
# - 对应原视频帧数：F = 4*(32-1)+1 = 125
#
# 为什么选 125 帧：
# - latent_T=32 足够长：dataset 的 out-window 能采到 current_frame_idx ∈ {16,20,24,28}
# - 且 current_frame_idx=24/28 > memory_frames(20)，会触发基于 FOV overlap 的“真正 memory 挑选”
#
# 建议训练参数：
# - WINDOW_FRAMES=16（=4 chunks）：既能进入 out-window，又能让 memory 选择生效
#

# 这里我们用了diffusion forcing（finetune本来就是diffusion forcing，所以我们直接load bidirectional_model）

  --hold_action_frames 4 --fixed_move_action_mode 4dirback --fixed_view_action ""
